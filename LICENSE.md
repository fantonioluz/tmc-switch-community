# Licenciamento por componente

Este repositório reúne código de diferentes projetos e não aplica uma licença
única a toda a árvore. Os avisos de autoria e as licenças dos componentes
originais continuam valendo; veja [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

A árvore-base não forneceu um arquivo de licença global na raiz. Esta edição
não presume uma licença MIT, GPL ou equivalente para todo o port e não muda
as condições dos autores originais. A ausência de uma licença global não deve
ser interpretada como uma licença nova concedida por este documento.

Os arquivos de licença encontrados estão preservados em `source/` e os textos
adicionais de bibliotecas estão reunidos em `LICENSES/`. O código-fonte do motor
de áudio derivado de agbplay está incluído em `source/libs/agbplay_core/`.

O jogo original, suas marcas, gráficos, músicas, textos e ROM não recebem uma
licença de redistribuição por meio deste projeto. O pacote para jogadores não
inclui uma ROM; cada jogador fornece seu dump. A pasta `release/switch/tmc/assets/`
contém os arquivos de execução fornecidos pelo mantenedor. A inclusão desses
arquivos não altera a titularidade nem concede uma nova licença para o conteúdo
do jogo original.
